# License scope / 许可范围

This file records the licenses present in the repository. It is **not** a new project-wide license grant. A single license covering all PiPER-Mate code, documentation and hardware has not yet been selected.

本文件记录仓库已有许可，**不构成新的整体许可授权**。覆盖 PiPER-Mate 全部代码、文档及硬件设计的统一许可尚未确定。

| Resource / 资源 | Existing evidence / 已有依据 | Scope / 范围 |
| --- | --- | --- |
| LeRobot PiPER adapter | [Apache-2.0 text](lerobot/lerobot_robot_piper/LICENSE) | This package / 本软件包 |
| LeRobot PiPER-Mate adapter | [Apache-2.0 text](lerobot/lerobot_teleoperator_pipermate/LICENSE) | This package / 本软件包 |
| ROS `piper` | [Apache-2.0 text](ros2-humble/src/piper/LICENSE) | This package / 本软件包 |
| ROS `piper_mate` | `setup.py` declares Apache 2.0; `package.xml` still has a TODO | Declaration conflict; no bundled license text / 声明不一致，未附许可全文 |
| ROS `piper_msgs` | `package.xml` has a TODO | Pending confirmation / 待确认 |
| Direct Python example and root CAN scripts | No dedicated license text supplied | Pending confirmation / 待确认 |
| STEP, SolidWorks, 3MF, drawings, images and documentation | No explicit blanket license supplied | Pending confirmation / 待确认 |

Earlier READMEs claimed a project-wide MIT license and linked a missing root `LICENSE`. That claim is not treated as evidence that the Apache-2.0 components or hardware files have been relicensed. Existing license texts and attribution are retained.

旧 README 曾声明整体 MIT 许可并链接缺失的根目录 `LICENSE`，该说法不能用来认定 Apache-2.0 组件或硬件文件已被重新许可。现有许可全文与署名保持保留。

Third-party dependencies remain under their own terms. Product images linked from the Fashion Star store are not covered by the software package licenses. Contact the maintainers through [Issues](https://github.com/servodevelop/piper-mate/issues) or [Fashion Star support](https://fashionstar.com.hk/support/) about resources whose permission scope is not yet specified.

第三方依赖继续适用各自条款。链接自 Fashion Star 商城的产品图片不属于上述软件包许可范围。对于许可范围尚未明确的资源，请通过 [Issues](https://github.com/servodevelop/piper-mate/issues) 或 [Fashion Star 支持](https://fashionstar.com.hk/support/)联系维护者。
