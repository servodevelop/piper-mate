## 📂 选择匹配资料

从[硬件资源表](../README.zh.md#resources)选择 CAD 和打印文件。先打开整机 STEP，再比对单件和 UC-01 外壳。两个打印配置存在差异，目前均没有新增实体验证报告。

<a id="print"></a>

## 🖨️ 打印前检查

项目面向 Bambu Lab P1S／PLA／0.4 mm 喷嘴。请在切片软件中核对打印盘内容、零件数量、朝向、支撑、逐对象覆盖参数及打印范围。原生 CAD ZIP 保留原文件名；导出新几何前先解决装配引用缺失。不能根据切片参数推断适配性、强度或承载能力。

<a id="assemble"></a>

## 🔩 核对装配与接线

依据 [BOM](../README.zh.md#bill-of-materials)核对数量与接头方向，参考[尺寸图](../drawings/piper-mate.pdf)。装连杆前核对舵机 ID 0–6 与机械零位。接线时断电，上电前检查极性和走线。完整的分步装配教程、紧固扭矩和接线针脚图尚未提供。

<a id="connect"></a>

## 🔌 开始首次连接

完成机械与电气核对后，进入[仓库快速开始](../../README.zh.md)。启用从臂运动前先确认主臂读数。
